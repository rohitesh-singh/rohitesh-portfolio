# Rohitesh Career Website v3

A recruiter-facing personal career site with:
- Role-specific positioning for TPM, Program Manager and AI Program Manager roles
- Career timeline using the current resume
- Interactive technical architecture visuals
- AI/automation case study
- Recruiter fit analyzer: paste a job description and get a browser-only alignment score
- Downloadable resume
- LinkedIn and email CTAs
- Responsive mobile design
- No build tools, dependencies or API keys

## Free deployment
Upload `index.html` and `resume.pdf` to GitHub Pages or import the folder into Vercel. No build command is required.

## Note
The fit analyzer is deliberately transparent and browser-only. It is a keyword signal to help tailor an application, not a prediction of hiring outcomes.
